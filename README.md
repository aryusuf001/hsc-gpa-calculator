# HSC GPA Calculator
A clean, high-performance open-source JavaScript logic built to calculate the Higher Secondary Certificate (HSC) GPA accurately based on the official Ministry of Education and Intermediate and Secondary Education Boards guidelines in Bangladesh.

## 🚀 Live Tool
The fully deployed, responsive, and user-friendly version of this utility is available here:
👉 **[HSC GPA Calculator (hscgpacalculator.com)](https://hscgpacalculator.com/)**

---

## ✨ Features
* **Full Grade Point Mapping:** Instantly converts raw subject scores/grades into individual Grade Points (GP) from 0.0 to 5.0.
* **4th Subject Rule Integration:** Dynamically handles the complex Bangladeshi optional (fourth) subject logic—automatically deducting 2 points from the 4th subject GP before calculating the total average.
* **Perfect Score Capping:** Ensures the final calculated score behaves strictly according to board rules (cannot exceed a total GPA of 5.0 / Golden A+ thresholds).
* **Lightweight & Fast:** Pure JavaScript execution ensuring immediate client-side calculation without heavy backend dependencies.
